# Коммерсант — Retro Edition · v1.2.0

Компактная пошаговая экономическая игра по мотивам DOS-«Коммерсанта» (1991) в стиле биржевого терминала 90-х.
Рынки: сырьё (нефть, земля), 10 акций S&P 500, 4 криптовалюты, коммерческая недвижимость с арендой,
собственность (жильё и транспорт), банк (вклад и кредит).

**Цель:** довести капитал (наличные + портфель + собственность + вклад − кредит) до целевой суммы за 250 ходов.
Поражение — банкротство, смерть героя или исчерпание ходов (их можно продлить — см. ниже).

## Что нового в 1.2.0

- **Имя игрока** вводится при старте, попадает в таблицу рекордов; сохранения именуются (`saves/<название>.json`).
- **Собственность** (вкладка `5`): 5 уровней жилья (конура → особняк) и транспорта (мопед → премиум-седан),
  ежемесячные коммунальные платежи и содержание авто, происшествия (кражи, поджоги, пожар, аварии, штрафы),
  охрана и страховка с 3-го уровня, болезни и смерть бездомного, арест и распродажа имущества банком за долги.
- **Аренда коммерческой недвижимости** — 10 / 15 / 20 / 25 % годовых от текущей цены объекта в зависимости от
  ситуации на рынке (как вклад, но ещё и цена объекта растёт или падает).
- **Торговые фигуры**: цены идут не просто случайно, а по формациям — бычий/медвежий тренд, флэт, восходящий и
  нисходящий клин, двойное дно и вершина, голова и плечи (в т.ч. перевёрнутая). Есть общий режим рынка
  (бычий / медвежий / боковой) и **чёрные лебеди** (пандемия, война в Персидском заливе, банковский кризис, крах
  криптобиржи, кибератака, чёрный понедельник, технологический прорыв).
- **250 ходов**, игровая **дата** и прошедшее время в шапке (1 ход = 1 неделя). Когда ходы кончились, игра предлагает
  добавить ещё 100 — в таблице рекордов такой результат помечается «без лимита ходов».
- **Пиктограммы** активов и собственности, цветные сообщения: неприятности — красным, приятное — зелёным.
- Вкладка «Банк» теперь на клавише `6`.

## Запуск

Нужен Python 3.11+.

```bash
pip install -r requirements.txt
python main.py
```

Тесты: `python -m pytest`

Для передачи другу: `build_exe.bat` собирает автономную версию `dist\Commersant-win64.zip`
(Python не нужен), подробная инструкция для пользователя — в файле `commercial.man`.
Запуск из исходников двойным кликом — `start_game.bat`.

## Режимы времени

- **Пошаговый** — ход делается кнопкой `N`.
- **Реальное время** (`M`) — ход идёт сам каждые 1–12 с (`+` / `-` меняют скорость, `P` — пауза).
  При событии игра сама встаёт на паузу и ждёт подтверждения. Режим и скорость запоминаются.
- В пошаговом режиме о событиях сообщает выпадающая плашка (красная — неприятность, зелёная — удача);
  чёрные лебеди и арест имущества показываются окном всегда.

## Карточка актива

Выбранная строка подсвечена полосой и маркером ▶. График за период 10 / 30 / 60 ходов / вся история (`T`),
фаза цены (падение, восстановление, рост, пик, боковик) с подсказкой, пунктир — ваша средняя цена покупки
и результат по позиции.

## Торговые фигуры

Каждый актив время от времени «входит» в фигуру длиной 12–24 хода, поверх которой накладывается случайный шум.
Фигуры разворота (двойное дно, перевёрнутая голова и плечи, нисходящий клин) обычно заканчиваются ростом,
двойная вершина, голова и плечи и восходящий клин — падением, флэт — движением в коридоре. Когда фигура пройдена
больше чем наполовину, в карточке актива появляется подсказка «Формируется фигура…». Режим рынка (в строке
состояния) смещает выбор фигур в сторону роста или падения. Чёрные лебеди бьют по ценам сразу и затем
постепенно восстанавливаются.

## Собственность

Игрок начинает с конурой и мопедом. Жильё и транспорт можно менять (старое продаётся за 85% цены, доплачивается
разница) и продавать. Коммунальные платежи и содержание авто списываются раз в месяц (каждые ~4 хода) —
сначала из наличных, потом со вклада.

- С **3-го уровня** жильё охраняется, а жильё и авто застрахованы: грабители не страшны, а пожар, затопление
  или авария приносят **компенсацию**. На низких уровнях — кражи, бомжи, поджоги, поломки, штрафы.
- **Без жилья** первые 4 хода — только предупреждения; с 5-го хода начинаются болезни (счёт за лечение),
  третья болезнь — смерть и конец игры. Нет денег на лечение — смерть сразу.
- **Долги**: при дефолте по кредиту банк сразу арестовывает и продаёт имущество (машину, затем жильё) за 70% цены;
  при двух ходах подряд с отрицательными наличными — то же самое.

## Правила в двух словах

- На ходу можно торговать сколько угодно; «Следующий ход» пересчитывает рынок и запускает случайное событие.
- В начале хода начисляются аренда (недвижимость), проценты по вкладу и кредиту.
- Покупка идёт по цене «куп», продажа — по «прод» (спред зависит от рынка).
- Кредит нужно вернуть в срок: при просрочке — дефолт, штраф, списание долга и арест имущества.
- Окно фиксированное (860×630), сохранения — `saves/<название>.json`, рекорды — `saves/highscores.json`.

## Горячие клавиши

Буквенные клавиши работают и в русской раскладке (B = И, S = Ы и т. д.), и во время ввода количества.

| Клавиша | Действие |
|---|---|
| `1` … `6` | Вкладки: Сырьё, Акции, Крипта, Недвижимость, Собственность, Банк |
| `↑` / `↓` | Выбор актива в таблице |
| `Q` | Фокус на поле количества / суммы (`Esc` — выйти из поля) |
| `B` или `Enter` в поле | Купить указанное количество |
| `S` | Продать указанное количество |
| `Z` / `X` / `C` | Купить 25% / 50% / максимум |
| `Shift+Z` / `Shift+X` / `Shift+C` | Продать 25% / 50% / всё |
| `N` или `Ctrl+Enter` | Следующий ход |
| `M` / `P` | Режим пошаговый ↔ реальное время / пауза |
| `+` / `-` | Скорость реального времени |
| `T` | Период графика: 10 / 30 / 60 / все |
| `Ctrl+S` / `Ctrl+L` | Сохранить (с названием) / загрузить из списка |
| `Ctrl+N` | Новая игра |
| `Ctrl+R` | Таблица рекордов |

Вкладка «Собственность»:

| Клавиша | Действие |
|---|---|
| `←` / `→` | Переключиться: жильё ↔ транспорт |
| `↑` / `↓` | Выбор варианта в списке |
| `B` | Купить / переехать на выбранный вариант |
| `S` | Продать текущее |

Вкладка «Банк» (пустая сумма = максимум):

| Клавиша | Действие |
|---|---|
| `D` | Положить на вклад |
| `W` | Снять со вклада |
| `L` | Взять кредит |
| `R` | Погасить кредит |
| `Z` / `X` / `C` | Подставить 25% / 50% / все наличные в поле суммы |

```
ui/     theme (QSS), icons (пиктограммы), widgets (график, лента, плашка), dialogs, main_window
tests/  pytest: engine, market, events, patterns, life (собственность, сохранения, рекорды), analysis
```

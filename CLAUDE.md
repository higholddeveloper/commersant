# ТЗ: Мини-игра «Коммерсант» (Python)

## 1. Цель и формат
Разработать компактную экономическую мини-игру «Коммерсант» на Python по мотивам классической DOS-игры 1991 года.
- Формат: компактное окно фиксированного/аккуратного размера (например, ~820x560 px), без полноэкранного режима, всё ключевое видно без прокрутки.
- Управление: равноценно удобное мышью (кнопки, выбор лотов) и с клавиатуры (горячие клавиши + Enter/Esc).

## 2. Игровой цикл и экономика
- Игрок начинает с заданным капиталом, портфелем активов (Нефть в баррелях/единицах, Земля в участках/сотках) и счётчиком ходов/дней.
- На каждом ходу игрок может совершать сделки (покупка/продажа нефти и земли по текущей цене с учётом комиссии/спреда) и/или завершить ход («Следующий ход»).
- При переходе на следующий ход:
  1. Пересчитываются цены на нефть и землю (базовый тренд + волатильность + влияние активных рыночных факторов).
  2. Срабатывает случайное событие (рыночное, финансовое, форс-мажорное или удачное) с понятным описанием и числовым эффектом (изменение цены, списание/начисление средств, потеря/прирост актива или временный модификатор).
  3. Проверяются условия победы/поражения (достижение целевого капитала, лимит ходов или банкротство/уход в глубокий минус).

## 3. Интерфейс (компактное окно)
- Верхняя панель: текущий ход/день, наличные деньги, оценка портфеля, общий капитал, цель/статус.
- Центральная часть:
  - Блок торговли (Нефть и Земля): текущая цена, изменение в %, количество на руках, быстрые кнопки/поля покупки и продажи (включая «25% / 50% / Макс»).
  - Мини-график динамики цен за последние ходы.
- Нижняя часть:
  - Текущее событие хода + краткий лог последних событий.
  - Кнопки управления ходом, сохранения/загрузки и новой игры с подсказками горячих клавиш.

## 4. Архитектура и качество кода
- Разделить логику игры (`core/` — экономика, события, состояние, сохранение) и UI (`ui/`).
- Покрыть базовую игровую логику и генератор событий unit-тестами (`pytest`).
- Добавить `README.md` с инструкцией по запуску и списком горячих клавиш.
- Работать итерациями: сначала предложить структуру проекта и ядро логики, дождаться подтверждения, затем собрать UI и тесты.

## Дополнение к ТЗ: Ретро-стиль и расширенные рынки

### Визуальный стиль
- Оформить интерфейс в духе ретро-терминала 90-х (DOS / старый Bloomberg): тёмный фон (#0B1020 или #000080), моноширинный шрифт, контрастные цвета (зелёный для роста, красный для падения, янтарный/голубой для акцентов), компактное окно (~860x580 px).
- Использовать библиотеку `Dear PyGui` (или `PySide6` с QSS-темой в стиле ретро-терминала) для чёткой работы и мышкой, и с клавиатуры.

### Структура вкладок (переключение кликом и клавишами 1–5)
1. `[1] Сырьё` — классика: Нефть и Земля.
2. `[2] Акции` — 10 компаний S&P 500 (NVDA, AAPL, MSFT, AMZN, GOOGL, META, TSLA, JPM, V, BRK) с разной базовой волатильностью.
3. `[3] Крипта` — 4 монеты (BTC, ETH, SOL, DOGE) с высокой волатильностью.
4. `[4] Недвижимость` — 4 типа объектов (Студия, Кофейня, Офис, Склад), покупаются поштучно и приносят пассивный доход (аренду) в начале каждого хода.
5. `[5] Банк` — простой вклад под процент и кредит с риском дефолта/штрафа.

### Механика событий
- Добавить пул событий для каждого рынка + кросс-рыночные события (например, повышение ставки ЦБ, глобальная паника, взлом биржи, бум аренды, авария в недвижимости).
- События должны быть короткими (1–2 строки) и сразу отображаться в нижней ретро-ленте новостей.
- Сохранить простоту: никаких сложных графиков свечей, плечей или шортов — только «купил дешевле, продал дороже» + пассивный доход от недвижимости и банка.

# CLAUDE.md — Мини-игра «Коммерсант» (Retro Python Edition)

## 1. О проекте
Компактная пошаговая экономическая мини-игра на Python по мотивам классической DOS-игры «Коммерсантъ» (1991), дополненная современными рынками (акции S&P 500, криптовалюта, недвижимость с пассивным доходом и банк).

**Главные принципы:**
- **Простота и динамика:** никаких сложных биржевых стаканов, плечей, шортов и свечных графиков. Суть: поймать волну, пережить форс-мажор, приумножить капитал.
- **Компактное окно:** фиксированный или аккуратный размер (~`860x580` px), без полноэкранного режима, всё ключевое видно без прокрутки.
- **Гибридное управление:** все действия одинаково удобно выполняются и **мышью**, и **клавиатурой** (горячие клавиши подписаны прямо на кнопках/вкладках).
- **Ретро-эстетика:** стиль старого биржевого терминала 90-х / DOS (тёмный фон `#0B1020` или `#000080`, моноширинный шрифт, контрастные цвета: зелёный рост, красный спад, янтарный/голубой акцент, чёткие рамки).

---

## 2. Технологический стек
- **Язык:** Python 3.11+ (строгая типизация, `dataclasses` / `enum`).
- **GUI:** `PySide6` (с ретро-темой через QSS) **или** `Dear PyGui` — выбрать на Шаге 1 один вариант и придерживаться его до конца.
- **Хранение данных:** локальный JSON (`saves/savegame.json`, `saves/highscores.json`).
- **Тесты:** `pytest` для бизнес-логики (`core/`).
- **Зависимости:** минимальный набор, всё фиксируется в `requirements.txt`.
